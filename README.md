# Analysis of Hotel Revenue 📊

## Project Synopsis

The main goal of this project is to use Power BI to analyze hotel revenue data. In order to facilitate data-driven decision-making in the hospitality industry, it records crucial business metrics like total bookings, cancellations, and no-show rates.

## Important Points

Power BI is the dashboard platform. **Visualized Data Metrics**:
  - Total reservations: over 135,000
  - No-Show Reservations: 7,000+% Each metric's contribution is shown in detail.
**Business Insights**:
  - Identifies possible revenue loss from no-shows - Assists in understanding guest booking behavior
  Encourages data-driven enhancements to the booking approach

## Goals

to use data visualization techniques to provide revenue teams and hotel management with actionable insights. By examining consumer patterns and operational bottlenecks, the objective is to minimize losses and maximize booking capacity.
